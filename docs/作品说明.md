# 作品说明：代码书锦绣，指尖颂家国

## 一、作品组成

本作品围绕“指尖颂家国”主题，提交两部分内容：

1. **Web 动态贺卡**（HTML / CSS / Canvas，主作品）：一段 54.5 秒的六幕动画，从启幕、五星红旗、锦绣山河、深情告白到烟花盛典与祝福祖国，支持点击放烟花、播放暂停、重播、全屏等交互。
2. **Python 国旗绘图**（turtle）：按 1949 年《国旗制法说明》的国标几何，用代码绘制五星红旗，并附 30×20 国标网格与 18 项几何自检。

## 二、创意构思

“指尖”可以同时是“代码之手”和“点击之手”：用一粒粒粒子、一个个像素去拼出对祖国的表白。

六幕叙事：

1. 启幕：夜空下亮起“我爱你中国”，点击任一位置都能放一朵烟花；
2. 五星红旗：国旗按国标几何逐笔升起，可按 G 键对照 30×20 网格；
3. 锦绣山河：约 2.3 万个光点从地图下方中心向外汇聚，拼出中国版图；
4. 深情告白：粒子组成“我爱你中国”“祖国万岁”字样，如文字烟花绽放；
5. 烟花盛典：五角星、心形与彩色烟花在夜空中盛放；
6. 祝福祖国：1949—2026 ｜ 成立 77 周年，把祝福定格在画面中央。

## 三、实现过程

**Web 贺卡**

- 用时间轴驱动六个场景，每一帧画面都由“当前时刻”计算得出，动画可暂停、可跳转、可重播；
- 国旗模块实现国标几何：30×20 网格、五颗星的半径与位置、小星指向大星中心的角度计算；
- 地图模块把公开行政区划数据做 Albers 等积圆锥投影，再扫描线取点、按距离分批缓存，保证 2.3 万个点也能流畅汇聚；
- 烟花引擎使用粒子池与预渲染发光贴图，心形、五角星和文字都通过离屏画布采样生成粒子目标点；
- 交互层：点击放烟花，空格暂停，R 重播，G 显示网格，F 全屏。

**Python 国旗**

- turtle 按国旗制法说明逐步落笔绘制；五角星内顶点半径用黄金比推导；
- `--verify` 自动校验 18 项几何关系；`--grid` 叠加国标网格；`--shot` 输出截图。

**演示视频**

- 利用确定性渲染，用无头浏览器逐帧截图，再合成 1920×1080、30fps 的 MP4 成品视频，与实时播放画面一致。

## 四、自研与 AI 使用声明

作品的核心代码逻辑与创意构思均由本人独立完成：场景叙事、时间轴设计、国标国旗几何、地图投影与点阵、粒子烟花引擎、交互逻辑均为自主实现。

开发过程中使用 AI 工具仅作为辅助：帮助排查语法错误、解释运行报错、提示调试方法；成品代码与画面均由本人编写与调整，未直接复制 AI 生成的成品。

## 五、运行环境与操作

**Web 贺卡**：直接用浏览器打开 `web/index.html` 即可，无需服务器，无第三方依赖；参数 `?t=`、`?scene=`、`?grid=1`、`?hud=0` 可直达指定画面。

**Python 国旗**：需要 Python 3 环境（含标准库 turtle）；常用命令见 README。
